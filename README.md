One-line entry for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty.

The safety warning label that should come printed on every human being:
a choking-hazard / small-parts notice, applied to the human itself.

> WARNING: Contains small parts. This human ships with one loose screw, no spare patience, and an attention span small enough to choke on.

Run `python3 main.py` to write the entry to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
